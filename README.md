# Fundamentals of Data Science Lab

This repository contains Python implementations of **Fundamentals of Data Science (FDS) Lab Experiments 1–4** using a college-area vehicle rental dataset.

## Experiments

### Experiment 1: Basic Data Exploration
- Summary statistics
- Mean, Median, Mode
- Variance and Standard Deviation
- Range
- Histograms
- Scatter Plots

### Experiment 2: Data Cleaning
- Detection of missing values
- Missing-value percentage
- Mean and Mode Imputation
- Quartiles (Q1 and Q3)
- Interquartile Range (IQR)
- Outlier detection using the IQR method
- Outlier removal

### Experiment 3: Hypothesis Testing
- Welch's Independent Samples t-test
- Chi-Square Test of Independence
- Null and Alternative Hypotheses
- p-value based decision making
- Statistical significance

### Experiment 4: Simple Linear Regression
- Independent and dependent variables
- Calculation of slope and intercept
- Regression equation
- Prediction of rental prices
- Regression-line visualization

## Dataset

The experiments use a **college-area vehicle rental dataset** containing variables such as:

- Distance
- Duration
- Rental Price
- Vehicle Type
- Customer Rating
- Demand Level
- Traffic Level
- Weather
- Vehicle Availability

## Technologies Used

- Python
- Pandas
- Matplotlib
- SciPy

## Key Concepts

This lab demonstrates practical applications of:

**Data Exploration → Data Cleaning → Statistical Inference → Predictive Modeling**
